# Atlas — Agentic RAG Multi-Tool Assistant (MCP)

This is the complete source project updated to use the Model Context Protocol (MCP).
The previous React UI has been replaced with the updated Atlas light UI.

## Architecture

```text
User
  ↓
React / Vite
  ↓
FastAPI
  ↓
Custom Agent + MCP Client Manager
  ↓
 ┌───────────────────────────────┐
 │ MCP Servers (stdio)           │
 │                               │
 │ RAG MCP Server                │
 │   └─ search_documentation     │
 │                               │
 │ Python Code MCP Server        │
 │   └─ execute_python_code      │
 │                               │
 │ Calculator MCP Server         │
 │   └─ calculate_expression     │
 └───────────────────────────────┘
  ↓
ChromaDB / local Python sandbox / calculator
```

The Agent Core does not directly execute the RAG, Python, or calculator implementations.
It discovers MCP tools with `list_tools()` and invokes them with `call_tool()`.

## Backend setup

```powershell
cd backend

python -m venv .venv
.venv\Scripts\Activate.ps1

pip install -r requirements.txt

copy .env.example .env

ollama pull qwen2.5:3b

python -m app.ingestion

python run.py
```

The first MCP startup should print messages showing the three MCP servers being
connected and their tools discovered dynamically.

## Frontend setup

Open a second terminal:

```powershell
cd frontend
npm install
npm run dev
```

Open the Vite URL shown in the terminal, normally:

```text
http://127.0.0.1:5173
```

## Important

`backend/chroma_db/` is generated by ingestion and is intentionally empty in this
source package. Run:

```powershell
python -m app.ingestion
```

to build the local vector database from the included PDFs.

`.venv/` and `node_modules/` are intentionally not packaged because they are
machine-specific installed dependencies. They are recreated with the setup commands
above.

## MCP acceptance checks

- `agent.py` contains no direct RAG/Python/calculator execution implementations.
- Tool implementations are isolated under `backend/servers/`.
- MCP tools are discovered through `list_tools()`.
- Tool execution uses MCP `call_tool()`.
- MCP transport is local stdio.
- RAG results retain source document and page metadata for citations.
